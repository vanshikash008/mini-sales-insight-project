## Mini Sales Data Analysis & Dashboard 📊  

This repository contains a **sales database** with multiple datasets and a **Power BI dashboard** for data visualization and insights.  

## 📂 Files in This Repository  
- **📁 Data** (Contains sales-related CSV & SQL files)  
  - `customers.csv` – Customer details  
  - `products.csv` – Product information  
  - `markets.csv` – Market segments  
  - `dates.csv` – Date-related data  
- **📊 Power BI Dashboard** (`Sales_Dashboard.pbix`) – Interactive visualization of sales insights  
- **🖼️ Screenshots** – Sample images of the dashboard  

## 🚀 How to Use  
1. Download the dataset and import it into SQL or Excel.  
2. Open the Power BI file (`.pbix`) to explore the dashboard.  
3. Use SQL queries for deeper analysis.  

## 📌 Key Insights  
- Customer behavior trends  
- Sales performance by product and region  
- Market segmentation analysis  

Feel free to contribute or suggest improvements! 😊
